# Backrooms Text-Based Game

This is a small text-based game of the Backrooms made in Python.

## Credits

### Development

**LogicGalaxy**  
Creator and sole coder of `main.py`. Came up with the idea for turning
the Backrooms into a text-based game and created the entire map for
Level 0. Also made many changes to `map.json` and is working on revising
the room descriptions.

Additional contributions include the torch mechanic, which allows the
player to see certain rooms, and the flickering wall mechanic that
allows the player to travel from Level 0 to Level 1. Level 1 and other levels are planned
for a future updates.

**Tjisan**  
Contributed changes to the descriptions of rooms and plans to contribute
additional descriptions for different levels.

**29rjj29**  
Contributed to the room descriptions for Level 0 and came up with the
second sentence of the first message displayed by `main.py`.
